# KCD2RP Wiki — энциклопедия Богемии

**Рабочая Wiki v0.4 с каталогами игровых предметов, рецептов, иконок, анимаций и картой** — расширенная версия отдельного сайта по принципам присланной подборки страниц Majestic Wiki. Оригинальные исходники, графику, тексты и фирменные элементы Majestic проект не копирует. Используются общие паттерны энциклопедии — категория, поиск, фильтры, таблица, подробная статья, связанные материалы, история обновлений.

## Новое в версии 0.2 — импорт игровых данных

Из серверного архива `archive(20261108-211057).tgz` импортировано:

- **5 323 записи предметов** из русифицированного каталога NPC/экспорта KCD2. В нём сохранены GUID, внутренние и английские названия; название может оставаться латиницей, если так указано в исходнике.
- **876 записей рецептов:** 76 базовых рецептов RP, 200 нативных рецептов игры и 600 дополнительных рецептов-кандидатов из серверного `craft_catalog.lua`.
- Для **395 предметов** присутствует справочная цена из `native_craft_data.lua`. Это не актуальная цена торгового NPC.
- В рецептах показываются выход, профессия, уровень, ингредиенты, время, опыт и плата в тех случаях, когда данные есть в исходнике.
- Отдельные страницы `/game/items`, `/game/recipes`, `/game/item/GUID` и `/game/recipe/ID` с поиском, фильтрами и постраничной загрузкой через `/api/game/...`.
- В панели редактора добавлен **импорт каталога в JSON**. Удалять или переписывать статьи для его обновления не требуется.
- Автономный `public/demo.html` теперь содержит и статьи, и реальные каталоги; редактирование в демо по-прежнему недоступно.

**Точность данных:** 600 дополнительных рецептов добавляются сервером только после проверки GUID в игре. Импорт Wiki выполняется без игрового движка, поэтому помечает их **«Дополнительный · требует проверки»** и не обещает доступность всех 600. Нативные таблицы тоже не подтверждают, какие рецепты сейчас разрешены конкретному персонажу.

### Как обновить уже установленную Wiki v0.1

**Не удаляйте `data/wiki.json`: там все ваши правки!** Используйте новую версию исходников, затем:

```bash
# В каталоге распакованного проекта, на сервере с установленной v0.1:
sudo bash deploy/update-existing-wiki.sh "$(pwd)" /srv/kcd2rp-wiki
```

Скрипт резервирует текущий `data/wiki.json`, обновляет серверный код, каталог и интерфейс, а затем перезапускает `kcd2rp-wiki`, если служба существует и запущена. Он **не перезаписывает** `data/wiki.json` или `/etc/kcd2rp-wiki.env`. Перед публикацией перепроверьте путь службы/Node и HTTPS-конфигурацию.

Для загрузки нового каталога через сайт перейдите в **Панель редактора → Импорт игровых каталогов** и выберите `game-catalog.json`. Через Nginx для этого нужен `client_max_body_size 10m` (изменение есть в `deploy/nginx.conf`). Перед заменой JSON сервер делает резервную копию, хранит до пяти предыдущих копий.

### Как собрать каталог из следующего игрового архива

На компьютере разработчика потребуются **Python 3.10+ и `texlua`** (для чтения экспортированных Lua-таблиц). Не запускайте импорт над недоверенными архивами; он исполняет включённые Lua-модули в тестовом окружении.

```bash
python3 tools/import_game_catalog.py --archive '/path/to/archive.tgz'
# или из распакованного игрового режима:
python3 tools/import_game_catalog.py --gamemode '/srv/kcd2-rp/app/gamemodes/localrp'
# после пересборки каталога обновить автономную демоверсию:
python3 tools/build_demo.py
```

Результат: `catalog/game-catalog.json`. Для немедленного обновления на живом сайте загрузите его через кабинет администратора либо разместите в проекте и перезапустите сервис. В последнем случае файл **`data/game-catalog.json` имеет приоритет над `catalog/game-catalog.json`**, если ранее каталог загружался через панель редактора; это позволяет сохранять обновления при развёртываниях.

## Реализовано

- React-интерфейс в едином стиле KCD2RP: чёрные панели, оттенок `#111116`, малиновый акцент, квадратные/умеренно скруглённые элементы, мобильная навигация.
- Главная, **9 разделов**, **38 стартовых статей и каталогов**, переключение страниц без перезагрузки.
- Поиск по заголовкам, описаниям, тегам и обычному тексту статей; фильтр по разделу и типу страницы.
- Полные статьи, оглавление с прокруткой, связанные материалы, блоки текста, списки, примечания, таблицы.
- Действующий кабинет администратора: вход по паролю, создание/редактирование/удаление статей, публикация черновика, редактирование блоков и таблиц.
- Node.js HTTP API без дополнительных npm-пакетов, постоянное сохранение в JSON (`data/wiki.json`), доступ по HTTPS через Nginx.
- Проверка администраторской сессии (HttpOnly, SameSite, HMAC), ограничение попыток входа и проверка Origin.
- Кнопка подключения к серверу по `kcdmp://connect/play.kcd2rp.ru:7777`.

**Важно:** базовые статьи остаются первичным наполнением на основе описания механик KCD2RP; они не являются официально утверждёнными правилами. Каталоги предметов и рецептов уже импортированы из доступных файлов сервера. **Не импортированы все возможные предметы KCD2**, нет реальной карты и актуальных данных онлайна. Недоступные значения не выдумывались.

## Запустить на Windows/macOS/Linux

Требуется **Node.js 18+**, npm install не нужен.

1. Скопируйте папку проекта на компьютер или сервер.
2. Сгенерируйте надёжные пароль и секрет (никогда не публикуйте их):

   ```bash
   openssl rand -hex 32
   ```

3. Запустите:

   ```bash
   cd /srv/kcd2rp-wiki
   export NODE_ENV=production
   export HOST=127.0.0.1
   export PORT=3082
   export WIKI_ADMIN_USER=admin
   export WIKI_ADMIN_PASSWORD='ВАШ_ДЛИННЫЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ'
   export WIKI_SESSION_SECRET='ВАШ_СЛУЧАЙНЫЙ_СЕКРЕТ_МИНИМУМ_32_СИМВОЛА'
   node server.js
   ```

   В Windows PowerShell используйте `$env:WIKI_ADMIN_PASSWORD="..."` и остальные переменные по аналогии.

4. Откройте `http://127.0.0.1:3082` локально. На публичном сайте обязательно используйте **HTTPS**.
5. Для редактирования кликните «Для редакторов» внизу бокового меню или откройте `/admin`.

**Не используйте** тестовый пароль из наших проверок. Он не включён в архив.

## Автономный просмотр дизайна

Откройте `public/demo.html` в браузере. Демоверсия содержит статьи прямо в HTML и показывает интерфейс без запущенного API; **сохранение и вход администратора в ней недоступны**. Для редактирования запускайте `server.js`.

## Debian 13 / Nginx / systemd

В комплекте есть примеры `deploy/kcd2rp-wiki.service` и `deploy/nginx.conf`. Они рассчитаны на отдельный поддомен, например `wiki.kcd2rp.ru`. Замените `wiki.example.ru` и пути перед применением. HTTPS-сертификат необходимо настроить самостоятельно.

1. Создайте отдельного системного пользователя без shell и каталог `/srv/kcd2rp-wiki`.
2. Разместите код проекта в `/srv/kcd2rp-wiki`, `data` сделайте доступным для записи пользователю сервиса.
3. Создайте `/etc/kcd2rp-wiki.env` с переменными из `.env.example`; `chmod 600 /etc/kcd2rp-wiki.env`.
4. Установите сервис и конфигурацию Nginx. Выполните `nginx -t` перед перезагрузкой.
5. Создайте HTTPS-сертификат для поддомена и включите `systemctl enable --now kcd2rp-wiki`.

Содержимое `data/wiki.json` **нельзя удалять при обновлениях**: в нём находятся статьи и правки администратора. Копируйте его при резервном копировании. `seed.json` используется только для первичного наполнения новой базы.

## Структура

```text
kcd2rp-wiki/
  server.js                # API и статические файлы
  seed.json                # стартовые статьи (не перезаписывает существующие)
  game-catalog-api.js      # поиск/фильтры/импорт игровых данных
  catalog/game-catalog.json # 5 323 предмета + 876 рецептов
  tools/                   # повторный импорт из архива + автономная демоверсия
  data/wiki.json           # редактируемые статьи, НЕ удалять
  data/game-catalog.json   # появляется после загрузки каталога через администратора
  public/index.html        # рабочий сайт
  public/demo.html         # просмотр без сервера
  public/app.js            # React-приложение
  public/style.css         # стили KCD2RP
  public/vendor/           # React runtime, MIT license
  deploy/                  # systemd + Nginx + безопасное обновление
  README.md
```

## Что нужно для полноценной игровой энциклопедии

1. Дополнить импорт другими категориями, иллюстрациями и анимациями; проверить кандидаты рецептов по логу реально запущенного игрового сервера.
2. Интеграция с БД KCD2RP через **отдельный read-only API** (не подключайте публичную Wiki напрямую к игровой MariaDB).
3. Интерактивная карта с географической калибровкой и данными регионов.
4. Загрузка/хранение иллюстраций и карточек предметов с учётом прав на изображения.
5. Если редакторов будет несколько — индивидуальные учётные записи, роли, история версий и аудит изменений.
6. Обновить локально включённый React 16.0 (в комплекте для полностью автономного запуска) до поддерживаемой версии React при последующей сборке на современном bundler. Не путайте версию runtime с текущим релизом React.

## Безопасность и лицензии

- Зависимости Node/npm **не требуются**; встроенные файлы React/ReactDOM 16.0 лицензированы MIT, см. `THIRD_PARTY_NOTICES.md`.
- Пароли и секреты не встроены в публичные JS или HTML.
- Авторские изображения Majestic и их готовая энциклопедия не включены.
- Внешние данные на страницах React выводит как текст без исполнения HTML.
- Для публичного многоредакторского запуска потребуется расширенная CMS-модель с аудитом, а не общий пароль.

## KCD2RP Wiki v0.3 — анимации, атлас и изображения

Это обновление для v0.2. Оно **не изменяет** 38 исходных статей и 5 323 импортированных предмета / 876 рецептов.

### Что добавлено

- **Каталог из 9 006 анимаций** (`/animations`) из `ui/admin/animations.json` игрового архива. Поиск по названию, семейству, фрагментам, постраничная выдача и копирование ID. Семейства — из исходных метаданных, не придуманные категории.
- **Атлас Тросков и Кутна-Горы** (`/map`) из **46 JPEG-тайлов** игрового режима и двух облегчённых WebP-обзоров. Карта масштабируется и перемещается мышью, переключаются регионы.
- Редактор, вошедший в Wiki, может указать название точки интереса и **нажать на карту** для размещения метки; все метки сохраняются в `data/map-markers.json`. Метки остаются после перезапусков и обновлений. Есть удаление с подтверждением.
- **Изображения предметов**: на подробной странице предмета редактор может загрузить PNG/JPEG/WebP до 2 МБ. Файлы сохраняются в `data/media/items/<GUID>.<расширение>` и отображаются в каталоге и карточке предмета. SVG и произвольный HTML не принимаются. Без загруженного изображения используется нейтральная иконка.
- Модуль `wiki-extra-api.js`: `/api/animations`, `/api/animations/meta`, `/api/animations/:clip`, `/api/maps/meta`, `/api/maps/markers`, `/api/admin/item-image/:guid`.

**Ограничения данных:** архив не содержит файлов изображений для всех 5 323 предметов. Внешняя Wiki не может напрямую вызывать `KcdMp.itemIcon` из клиентского CEF игры. Поэтому реальные изображения нужно экспортировать из локальной игры с соблюдением прав на публикацию либо загрузить вручную. Изображения из случайного интернет-поиска не подставляются.

**О калибровке:** игровые координаты X/Y для положения игрока не сопоставлены с пикселями атласа автоматически. Эта версия сознательно **не показывает ложный маркер игрока**. Размещённые вручную метки имеют координаты **доли ширины/высоты изображения**, не координаты игрового мира. Для точной синхронизации нужно импортировать проверенные калибровочные точки KCD:MP 0.49.0 либо встроить серверный read-only экспорт с `worldToMap`.

### Установка поверх v0.2

Распакуйте обновление и запустите:

```bash
sudo bash kcd2rp-wiki/deploy/update-existing-wiki.sh ./kcd2rp-wiki /srv/kcd2rp-wiki
```

Установщик **делает резервную копию** `wiki.json`, `game-catalog.json` и `map-markers.json`, если они существуют, и **не перезаписывает** `data/` вообще. Если вы развернули проект с другой структурой, адаптируйте SOURCE и DEST. Для управления ресурсами нужны права на запись в `data/` у процесса Wiki.

Сервер Node.js продолжает работать на `127.0.0.1:3082`, новых npm-зависимостей нет. Для загрузки изображения ограничение Nginx `client_max_body_size 10m` из v0.2 уже достаточно.

### Исходники и права на изображения

Слои атласа были взяты из предоставленного архива игрового режима. Перед публичной публикацией проверьте права на распространение этих графических ресурсов; в данном комплекте они предназначены для развёртывания владельцем KCD2RP. Проект **не публиковался на домен и не подключён к MariaDB**.

### Автономный просмотр

В `public/demo.html` доступны каталоги, поиск анимаций и карты. Редактирование и сохранение новых данных требуют запущенного `node server.js`.

### Массовое добавление иллюстраций

Если изображения предметов уже экспортированы из собственной копии KCD2 и у вас есть право их публиковать, можно загрузить их сразу по соответствующим GUID, без ручной обработки 5 323 карточек. Подготовьте папку изображений и JSON-манифест (`tools/item-images.example.json`):

```bash
node tools/import-item-images.js --source /path/to/my-icons --manifest /path/to/my-icons.json --data /srv/kcd2rp-wiki/data --dry-run
# после проверки вывода, уберите --dry-run для импорта
```

Node.js 18+, дополнительных зависимостей нет. Манифест не содержит файлов изображений — их необходимо предоставлять отдельно. Не копируйте эти файлы в `catalog/` или `public/` при обновлении: храните в `data/media/items/`.

## Новое в версии 0.4 — реальные иконки предметов и библиотека графики

Из предоставленного `icons.rar` извлечены и переведены в WebP **4 939 PNG-изображений**: 3 421 иконка предметов, 877 перков, а также эффекты, характеристики, карта, комбо и остальные игровые категории. Размер комплекта WebP — приблизительно **10,6 МиБ**. Иконки лежат в `public/icons/`; архив PNG не нужен для работы сайта.

С помощью точного и консервативного сопоставления по *внутреннему игровому имени* удалось связать **2 614 из 5 323** записей предметов из доступного RP-экспорта: 2 572 точных совпадения, 8 нормализованных имён и 34 общие иконки качественных вариантов зелий. Для остальных 2 709 позиций картинка намеренно не подставлена, если нет проверенного совпадения.

- Каталог **`/game/items`** теперь показывает изображения найденных предметов; отдельные карточки сохраняют GUID и русские названия.
- Каталог **`/game/recipes`** показывает изображение результата изготовления там, где его можно сопоставить; на страницах рецептов отображаются иконки ингредиентов и результатов при наличии.
- Отдельная страница **`/icons`** показывает все 4 939 иконок по 18 категориям, с поиском по внутреннему имени, просмотром и копированием ID / относительного пути.
- Редакторские загрузки в `data/media/items/` имеют **приоритет** над встроенными иконками. Их обновление и переустановка Wiki не перезаписывают.
- Индексы `catalog/icons.json` и `catalog/item-icon-map.json` используются сервером для поиска. Вся графика хранится отдельно от базы статей.
- При повторном импорте `game-catalog.json` можно пересобрать сопоставление из нового каталога командой `python3 tools/rebuild_icon_map.py --catalog /path/to/game-catalog.json`, затем обновить `catalog/item-icon-map.json` на сервере и перезапустить Wiki. Команда не меняет статьи и карту.

### Обновить существующую Wiki v0.3

Распакуйте архив **Update v0.4** рядом с установленной Wiki и выполните команду из распакованной папки:

```bash
sudo bash deploy/update-existing-wiki.sh "$(pwd)" /srv/kcd2rp-wiki
```

Новый инсталлятор сохраняет редактируемые данные (`data/wiki.json`, импортированные каталоги, маркеры карты, пользовательские изображения), а также резервирует три JSON-файла перед копированием.

**Авторские права:** загрузчик содержит изображения оригинальной игры. Перед публикацией этих файлов на общедоступном сайте проверьте, разрешено ли распространение игровых ассетов через вашу Wiki. Система предназначена для работы с архивом, который предоставил владелец проекта, и не утверждает, что у файлов свободная лицензия.

**Важно:** данные карты по-прежнему не калиброваны к реальным координатам персонажей. Версия 0.4 меняет иконки и визуальную базу, не добавляет неподтверждённую геопривязку.
