# Публикация KCD2RP Wiki на GitHub Pages

Сайт собирается из текущих данных `data/wiki.json` (или `seed.json` для новой установки), игровых каталогов и графики. Node-сервер на GitHub Pages не запускается: публичная версия работает только для чтения. Вход, изменение статей, импорт каталогов и загрузка изображений доступны в исходной серверной версии (`npm start`).

## Сборка

Требуется Node.js 18+; внешние npm-зависимости не нужны.

```bash
npm ci
npm run check
npm run build:pages
npm test
npm run preview:pages
```

Локальный предпросмотр: `http://localhost:3082/KCD2Wiki/`. Каталог сборки — `dist/pages`; он не хранится в Git. Базовый путь определяется автоматически, поэтому одна сборка работает и на `https://<owner>.github.io/<repository>/`, и в корне отдельного домена. Внутренние страницы используют hash-маршруты (`/#/catalog`, `/#/game/items`), которые переживают перезагрузку без серверного fallback.

## Автоматическая публикация

Workflow `.github/workflows/pages.yml` запускается при изменении проекта в ветке `main`, а также вручную через **Actions → Deploy Wiki to GitHub Pages → Run workflow**.

Однократная настройка репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**. GitHub не позволяет workflow-токену самому создать Pages-сайт (`actions/configure-pages` с `enablement: true` требует прав администратора), поэтому workflow проверяет, что Pages включён, и при необходимости падает с понятной ссылкой на настройки. Пока репозиторий приватный, workflow пропускается без ошибки; видимость репозитория он не меняет.

После успешного задания `deploy` адрес появится в environment `github-pages` и в настройках Pages. Для репозитория `markuzewb/KCD2Wiki` ожидаемый адрес: `https://markuzewb.github.io/KCD2Wiki/`.

## Что попадает в публикацию

- Только опубликованные статьи (`published === true`) и настройки витрины.
- Каталоги предметов, рецептов, анимаций, иконок и меток карты.
- Публичная графика, стили, локальный React и уведомления о лицензиях.
- Явно выбранные изображения предметов из `data/media/items`.

`.env`, серверный код, резервные копии и черновики в артефакт Pages не копируются. Сборка не обращается к игровой базе данных и не содержит паролей редактора.

## Обновление содержимого

1. Отредактируйте данные в серверной версии или обновите JSON-файлы в репозитории.
2. Отправьте изменения в ветку, для которой настроен workflow.
3. Дождитесь успешных заданий `build` и `deploy`. GitHub Pages может кешировать файлы несколько минут; данные сборка запрашивает с ревалидацией.

Статический адаптер обслуживает поиск, фильтры и пагинацию в браузере. Большие каталоги загружаются только при открытии соответствующего раздела, а не на главной странице.
